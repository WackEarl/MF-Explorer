# MF Explorer

A fork of [Material Files](https://github.com/zhanghai/MaterialFiles). The package id is still `me.zhanghai.android.files`, but this fork is signed with a new key, so it does not replace an existing Material Files or debug install.

## Added in this fork

- NFSv3, with pipelined reads
- Folder tabs that survive a restart
- Running file jobs in the toolbar
- Export and import of settings, servers, tabs and folder view. The file stores passwords, SFTP private keys and WebDAV tokens in plain text.

## Also included

- Breadcrumb navigation
- Root access
- View, extract and create common archives
- FTP, FTPS, SFTP, SMB and WebDAV
- Custom colors, and a night mode with optional true black
- Symbolic links, file permissions and SELinux context
